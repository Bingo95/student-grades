# 2026-09-06

## 学习情况记录功能（student_record 项目 Home 页）

基于既有脚手架（Umi Max 4 + React 19 + antd-mobile v5 + @antv/f2 + ahooks）实现「成绩记录」功能，已在 `src/pages/Home` 下。

核心文件：
- `index.tsx`：底部 Tab 导航（记录 / 统计图 / 分数录入 / 导入导出）+ 详情弹窗编排
- `components/ExamForm.tsx` + `ExamForm.less`：分数录入表单，分数输入用 `VirtualInput` + 共享 `NumberKeyboard`（含小数点），预设语数英物化生 + 自定义学科（可删），考试时间用 antd-mobile `DatePicker`
- `components/RecordCard.tsx`：列表卡片，`SwipeAction` 左滑编辑/删除，点击查看详情
- `components/ExamDetailPopup.tsx`：详情（总分/得分率/排名/学科明细/环比）
- `components/OverviewCard.tsx` / `TrendCard.tsx` / `WeakSubjectCard.tsx`：概览、趋势（F2 折线，总分/单科切换）、弱势学科（按平均得分率对比）
- `components/ImportExportPanel.tsx`：JSON 导出 / 合并导入 / 覆盖导入 / 清空
- `hooks/useExamRecords.ts`：基于 ahooks `useLocalStorageState` 持久化（刷新不丢），并暴露 add/update/remove/replaceAll/mergeRecords/clearAll
- `utils/analyze.ts`：统计核心（总分、得分率、学科均值、弱势判定）
- `src/components/Chart/LineChart.tsx`：通用 F2 v5 折线图（命令式 Canvas 挂载，与既有 BarChart 同款模式）

风格：苹果简约风（浅灰背景 #f2f2f7、白卡片圆角、系统蓝 #007aff、得分率进度条暖色梯度）。less 单位按 750 设计稿（postcss 自动转 vw）。

校验：`tsc --noEmit` 0 错误；`npm run build` 成功（Home 独立分包 p__Home__index）。

注：分数输入按用户要求改为 VirtualInput + NumberKeyboard；状态管理统一用 ahooks（useBoolean/useMemoizedFn/useLocalStorageState）。
